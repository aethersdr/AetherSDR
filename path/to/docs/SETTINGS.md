Proactive Update Check
=====================

AetherSDR can now check for updates proactively. This feature is enabled by default, but can be disabled in the settings.

### Enabling/Disabling Update Check

To enable or disable the update check, follow these steps:

1. Open the settings window by clicking on the "Settings" button in the top-right corner of the main window.
2. In the settings window, click on the "Proactive Update Check" checkbox to enable or disable the update check.

### Update Check Frequency

The update check frequency is set to every hour. This means that AetherSDR will check for updates every hour, and display a notification if an update is available.

### Update Check Status

The update check status is displayed in the main window, below the "Update Check" button. If an update is available, the status will display "Update Available". Otherwise, the status will display "No Update Available".
