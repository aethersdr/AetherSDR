# AetherSDR Trademark Policy

The **AetherSDR** name and any associated logos are trademarks of Jeremy
Fielder (KK7GWY) and the AetherSDR project. They are distinct from the
code itself and are **not** granted by AetherSDR's source-code license
(AGPL v3 / GPL v3 — see [LICENSE](LICENSE)).

This policy exists so that the project name continues to mean *this*
project, and so that downstream users and contributors aren't confused
about who built or supports a given build.

## What you may do

* **Fork the code freely.** AGPL v3 / GPL v3 give you everything you
  need to copy, modify, distribute, and host the source. None of that
  requires permission to use the AetherSDR name.

* **Talk about AetherSDR.** Nominative use is fine: blog posts,
  reviews, comparisons, tutorials, "I use AetherSDR for …", linking to
  the project, screenshots that include the AetherSDR window title,
  community Discord/forum discussions, contest stories — all OK.

* **Build the source for personal use.** A local build you compiled
  yourself can keep the AetherSDR name and logo; nothing about
  personal use triggers this policy.

## What requires explicit permission

* **Distributing a modified binary under the AetherSDR name.** A fork
  with substantive code changes that's shipped to other people as
  "AetherSDR" (or a name that includes "AetherSDR") needs maintainer
  permission first. Without that, please choose a distinct name —
  something like "MyCallSign-SDR" or "ProjectName" — so users can
  tell what they're running. The code under the new name stays AGPL
  v3 either way; only the *name* requires the rename.

* **Hosting a modified AetherSDR as a service under the AetherSDR
  name.** Same principle: the service must accurately tell users
  whose modifications they're connecting to. Rename the service.

* **Commercial use of the name or logo.** Selling merchandise,
  branded support services, training courses, etc. that use the
  AetherSDR name or logo requires written permission.

* No grant of any trademark right is implied by your contribution

## Asking

When in doubt, ask. Open a discussion in the **Project Governance**
category on the [AetherSDR GitHub Discussions
board](https://github.com/aethersdr/AetherSDR/discussions), or reach
out to the maintainer directly.

This policy may be revised as the project grows. The current version
always lives at [TRADEMARK.md](TRADEMARK.md) in the AetherSDR repo.
